# CivicConnect — Municipal Digital Services Portal

An independently developed WordPress portfolio project from KnowEdge Business Development Services Ltd. It is not affiliated with a government or municipality.

## Features

- Custom responsive WordPress theme and editable service, department, news, document and event records.
- Live keyword search for services and public records.
- Local citizen request preview with no personal data collection.
- Rule-based citizen assistant for finding the relevant information.
- Keyboard-friendly menus, focus indicators, responsive navigation and reduced motion support.
- Sample downloadable documents and a public FAQ.

## Installation

Zip the `theme/civicconnect` directory, preserving the top-level `civicconnect` folder. In WordPress, select Appearance → Themes → Add Theme → Upload Theme. Activate the theme; its example content is seeded once. The project requires WordPress 6.5+ and PHP 8.1+.

The records are illustrative. A real deployment should replace them with approved public records and connect authorized request, scheduling and accessibility systems.
